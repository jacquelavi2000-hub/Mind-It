GUIDE OFFICIEL · MIND-IT MCP

Connecte Mind-It à ChatGPT.

Ce tutoriel t'accompagne pour relier ton compte Mind-It à ChatGPT, puis associer Mind-It Desktop. Une fois configuré, ChatGPT peut consulter tes appareils et envoyer des commandes autorisées à ton application.

Commencer le tutoriel ↓Aide officielle ChatGPT ↗
Disponibilité : la connexion personnalisée MCP dépend de ton offre ChatGPT et des règles de ton espace de travail. Si l'option « Add custom MCP server » n'apparaît pas, ton compte ou ton espace ne permet peut-être pas cette configuration. La disponibilité des actions d'écriture est également soumise aux restrictions de l'offre. Consulte la documentation OpenAI à jour.

Dans ce tutoriel

  1. Préparer Mind-It
  2. Ajouter le serveur MCP
  3. Configurer OAuth / DCR

ÉTAPE 01

Prépare ton compte Mind-It

Avant d'ouvrir ChatGPT, vérifie que tu as :

  • Un compte Mind-It et une clé API Mind-It active commençant par mi_live_.
  • Mind-It Desktop installé sur ton ordinateur.
  • Une connexion Internet sur l'ordinateur et dans ChatGPT.
Ne partage jamais ta clé API. Ne la colle pas dans une conversation ChatGPT, un e-mail, une capture d'écran ou un dépôt GitHub. Tu la saisiras uniquement sur la page sécurisée Mind-It affichée pendant l'autorisation OAuth.
ÉTAPE 02

Ajoute le serveur MCP dans ChatGPT

  1. Ouvre ChatGPT sur le Web.
  2. Ouvre la section Plugins / Applications, selon l'interface de ton compte.
  3. Clique sur +, puis sur Add custom MCP server / « Ajouter un serveur MCP personnalisé ».
  4. Donne-lui le nom Mind-It et, si tu le souhaites, la description « Connecte ChatGPT à Mind-It Desktop ».
  5. Dans le champ URL du serveur, colle cette adresse :
https://mind-it-server.onrender.com/mcp

Choisis l'authentification OAuth si ChatGPT te le demande. Ne choisis pas « No authentication » : Mind-It protège les données de chaque compte avec OAuth.

ÉTAPE 03

Configure l'inscription OAuth

Mind-It utilise OAuth 2.1 avec PKCE (S256) et l'inscription dynamique du client (DCR). Si ChatGPT demande les paramètres avancés, utilise ces valeurs :

Authorization serverhttps://mind-it-server.onrender.com
Authorization URLhttps://mind-it-server.onrender.com/oauth/authorize
Token URLhttps://mind-it-server.onrender.com/oauth/token
Registration URLhttps://mind-it-server.onrender.com/oauth/register
Token endpoint authenticationnone
PKCES256
Resource / Audiencehttps://mind-it-server.onrender.com/mcp

Scopes :

mindit:read mindit:write

Le serveur crée automatiquement un identifiant client public avec DCR : ne crée pas de client secret. Si ChatGPT propose de choisir entre DCR et un client OAuth défini manuellement, sélectionne DCR.

Valide l'avertissement de sécurité, puis clique sur Create as a plugin / « Créer comme plugin » si cette option est proposée.

ÉTAPE 04

Autorise ton compte Mind-It

  1. ChatGPT ouvre une page sécurisée sur le domaine Mind-It.
  2. Vérifie que l'adresse commence par https://mind-it-server.onrender.com/.
  3. Saisis ta clé API Mind-It sur cette page, jamais dans ChatGPT.
  4. Lis les permissions avant de les accepter.
  5. Autorise mindit:read pour la lecture. Accepte mindit:write uniquement si tu veux permettre à ChatGPT d'envoyer des commandes à Mind-It Desktop.
  6. Valide l'autorisation. ChatGPT termine ensuite la connexion.
Connexion autorisée !
La clé API reste entre Mind-It et son serveur. ChatGPT reçoit un jeton OAuth limité aux permissions que tu as acceptées.
ÉTAPE 05

Associe Mind-It Desktop

  1. Lance Mind-It Desktop sur ton ordinateur.
  2. Ouvre la page API & Connexions dans l'application.
  3. Utilise le flux d'appairage par code proposé par l'application et termine l'association de cet ordinateur à ton compte Mind-It.
  4. Vérifie que l'état du Bridge indique qu'il est connecté.
  5. Laisse Mind-It Desktop ouvert lorsque tu veux que ChatGPT lui envoie des commandes.

Un compte ChatGPT connecté ne signifie pas automatiquement qu'un ordinateur est appairé. L'appairage Desktop est une étape séparée : il relie ton installation à ton compte Mind-It.

ÉTAPE 06

Teste la connexion

Dans une nouvelle conversation ChatGPT, sélectionne Mind-It dans les applications disponibles, puis teste ces demandes :

Vérifie mon état de connexion Mind-It. Liste mes appareils Mind-It Desktop. Affiche mes cartes mentales Mind-It.

Les outils disponibles comprennent :

  • mindit_connection_status : vérifie la connexion sans révéler la clé API.
  • mindit_list_devices : affiche les appareils associés à ton compte.
  • mindit_send_desktop_command : envoie une action autorisée à Desktop.
  • mindit_get_command_result : vérifie le résultat de la commande.
Test réussi : ChatGPT voit ton appareil, Mind-It Desktop est ouvert et les commandes se terminent avec le statut « completed ».

Sécurité et dépannage

Je ne trouve pas « Add custom MCP server »

La disponibilité dépend de l'offre ChatGPT, du type d'espace de travail et de ses règles. La configuration MCP personnalisée et les actions d'écriture ne sont pas disponibles sur tous les comptes. Essaie depuis ChatGPT sur le Web et vérifie les autorisations de ton espace. Voir la page d'aide OpenAI.

La page Mind-It refuse ma clé API

Vérifie que la clé est encore active et qu'elle appartient à ton compte Mind-It. Si elle a été révoquée, crée une nouvelle clé depuis l'espace de gestion prévu par Mind-It. Ne transmets jamais la clé au support dans un message.

La connexion fonctionne, mais aucun appareil n'apparaît

Retourne dans Mind-It Desktop → API & Connexions et termine l'appairage de l'installation. Vérifie que l'application utilise le même compte Mind-It que la clé API autorisée.

ChatGPT n'arrive pas à envoyer une commande

Vérifie que la permission mindit:write a été acceptée, que l'appareil est appairé et que Mind-It Desktop est ouvert. Les commandes en attente expirent après cinq minutes.

La connexion expire après un certain temps

Dans la version actuelle du serveur, les jetons d'accès OAuth expirent après une heure et le renouvellement automatique par refresh token n'est pas encore disponible. Réautorise Mind-It si ChatGPT te le demande.

Comment couper l'accès ?

Révoque la clé API Mind-It associée depuis l'espace de gestion des clés : cela invalide les accès MCP liés à cette clé. Tu peux également déconnecter l'installation Desktop depuis Mind-It. Fermer la conversation ChatGPT ne révoque pas à lui seul l'accès serveur.

Besoin d'aide ?

Si tu bloques, note l'étape concernée et le message d'erreur exact. Ne partage ni clé API, ni jeton OAuth, ni code secret d'appairage.
