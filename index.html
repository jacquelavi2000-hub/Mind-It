Pour aller plus loin

Ce qui distingue chaque édition.

Ouvre une fiche pour consulter les détails sans alourdir le tableau.

Mind-It FreeGratuit
  • Outils de création et d’organisation de cartes, avec blocs standard, checklist et Options.
  • Assistant qui génère des branches à partir d’un texte selon des règles simples ; ce n’est pas un chat connecté à un modèle d’IA.
  • Sauvegarde automatique dans un fichier JSON choisi par l’utilisateur, avec import d’un fichier existant.
  • Limites indiquées dans le README : 3 projets, 3 cartes par projet, 100 blocs par carte et 3 options par bloc Options.
  • Les fichiers importés sont ramenés aux limites de la version Free.
Mind-It PremiumAvancé
  • Fonctionnalités de Free, avec blocs de liste, cases à cocher, marqueur rond ou carré et styles personnalisés des blocs.
  • Assistant utilisant un modèle d’IA local ; ses propositions de modification doivent être confirmées avant application.
  • Gestion et téléchargement de modèles IA, avec sélection d’un modèle et démarrage ou arrêt du moteur local.
  • Raccourcis configurables pour créer, supprimer, styliser ou renommer des blocs et sélectionner toute la carte.
  • Export des cartes en PNG.
  • Licence Premium vérifiée en ligne ; l’application reste verrouillée tant qu’une licence valide n’est pas confirmée.
Mind-It PlatinumTout-en-un
  • Fonctionnalités de Premium, plus des connexions libres multiples entre blocs, avec réglage de leur couleur et de leur épaisseur.
  • Chat avec le modèle IA local, gestion des conversations et propositions de modifications à confirmer.
  • Gestion des modèles GGUF locaux avec moteur llama.cpp ; profils matériels et budget RAM réglable.
  • Page API pour configurer une URL HTTPS, enregistrer une clé chiffrée et connecter l’application à un backend via Desktop Bridge.
  • Commandes API repérées : lecture paginée des cartes, création/modification/suppression et duplication de cartes et blocs, déplacement de cartes ou de branches, connexions, options, listes, mises à jour groupées et mise en page automatique.
  • La lecture paginée de get_map permet de récupérer une grande carte en plusieurs appels.
  • L’autorisation mindit:read / mindit:write doit être appliquée par le backend. Le pont Desktop exécute les commandes autorisées qu’il reçoit.
  • La licence Platinum vérifiée en ligne est requise pour utiliser le moteur IA local et le chat. La documentation indique que les modèles restent sur l’appareil et que le moteur écoute sur 127.0.0.1.

Fonctionnalités communes

Les trois éditions comprennent la création et la suppression de cartes et de projets, l’édition des titres de blocs, le déplacement des blocs, les blocs checklist et Options, la sélection multiple, la mini-carte, l’organisation de la disposition, le mode sombre, le réglage des lignes et la sauvegarde/importation JSON.

À noter : la collaboration partagée en temps réel n’est pas implémentée dans les éditions examinées. Le cahier des charges API Platinum comprend aussi des opérations qui ne sont pas toutes exposées dans l’interface graphique.

Les réponses utiles

Questions fréquentes.

Les informations essentielles pour télécharger Mind-It et comprendre l'accès Premium.

Comment télécharger Mind-It gratuitement ?

Utilise le bouton de téléchargement : il ouvre l'installateur Windows publié dans les GitHub Releases.

Mind-It est-il disponible sur Windows ?

Le téléchargement proposé ici est l'installateur Windows. Les autres plateformes ne sont pas annoncées sur cette page.

Que comprend Mind-It Premium ?

Après confirmation du paiement, le parcours Premium donne accès à une licence, au téléchargement Premium et aux mises à jour réservées aux licences valides. La page de paiement précise le montant et les conditions avant validation.

Comment fonctionne le paiement ?

Le bouton contacte le service Mind-It pour créer une session de paiement, puis t'envoie vers la page de paiement retournée par le service. Tu peux vérifier le prix et les conditions avant de confirmer ; aucun achat n'est effectué sur ce site.

Comment obtenir les mises à jour Premium ?

La page des mises à jour permet de vérifier la dernière version et de demander son téléchargement avec une clé de licence valide.
