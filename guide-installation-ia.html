GUIDE MIND-IT PLATINUM

Installer ton modèle IA localement.

Ce guide explique comment télécharger un modèle Qwen GGUF, l'importer dans Ollama sous Windows et le préparer pour Mind-It. Le modèle fonctionne sur ton ordinateur : choisis une taille compatible avec ta mémoire.

ÉTAPE 01

Vérifier l'accès Platinum

Ouvre le catalogue des modèles IA et entre ta clé Mind-It Platinum. Le serveur vérifie la licence avant d'afficher les téléchargements.

ÉTAPE 02

Installer Ollama

Si Ollama n'est pas encore installé, télécharge-le depuis son site officiel, puis installe-le sur Windows :

Télécharger Ollama pour Windows ↗

Après l'installation, Ollama fonctionne normalement en arrière-plan. Garde-le ouvert pendant l'utilisation de l'IA locale.

ÉTAPE 03

Télécharger un modèle Qwen

  1. Retourne dans le catalogue Mind-It.
  2. Renseigne le profil de performances de ton PC et sa RAM.
  3. Regarde la recommandation, puis télécharge un fichier GGUF. Pour commencer, une quantification Q4 est souvent un compromis raisonnable.
  4. Enregistre le fichier dans un dossier simple, par exemple C:\MindIt\Models\.
  5. Si le modèle est divisé en plusieurs parties, télécharge toutes les parties et conserve exactement leurs noms dans le même dossier.
La taille du fichier n'est pas égale à la RAM nécessaire. Il faut aussi de la mémoire pour Windows, le contexte et les autres applications. Les estimations du catalogue sont indicatives.
ÉTAPE 04

Créer un fichier Modelfile

Dans le dossier où tu as téléchargé le modèle, crée un fichier nommé exactement Modelfile (sans extension .txt). Ouvre-le avec le Bloc-notes.

Pour un modèle en un seul fichier, écris ceci et remplace le chemin par le nom exact de ton fichier :

FROM C:\MindIt\Models\mon-modele.gguf PARAMETER num_ctx 4096

Pour un modèle réparti sur plusieurs parties, conserve tous les fichiers dans le même dossier et utilise un motif qui correspond à toutes les parties :

FROM C:\MindIt\Models\mon-modele-*.gguf PARAMETER num_ctx 4096

Ollama documente l'import des fichiers GGUF via la commande FROM dans un Modelfile. Pour les modèles fractionnés, le motif doit correspondre à tous les fragments. Documentation officielle Ollama ↗

ÉTAPE 05

Importer le modèle dans Ollama

Ouvre PowerShell dans le dossier qui contient le fichier Modelfile et exécute :

ollama create mindit-qwen -f Modelfile

Attends la fin de l'import. Le traitement peut prendre un peu de temps selon la taille du modèle et ton ordinateur.

ÉTAPE 06

Tester le modèle

Dans PowerShell, exécute :

ollama run mindit-qwen

Si le modèle répond, l'import est réussi. Tu peux quitter le test avec /bye.

ÉTAPE 07

Connecter Mind-It

Dans Mind-It Platinum, ouvre les paramètres de l'IA locale et choisis le moteur Ollama, si cette option est disponible dans ta version.

  • Adresse locale : http://127.0.0.1:11434
  • Nom du modèle : mindit-qwen
  • Vérifie qu'Ollama est lancé avant d'utiliser l'assistant.
Terminé ! Ton modèle est importé dans Ollama et prêt à être testé localement. Les performances dépendent du processeur, de la mémoire et de la taille du contexte.
AIDE

En cas de problème

  • Ollama n'est pas reconnu : ferme puis rouvre PowerShell après l'installation.
  • Erreur de fichier : vérifie le chemin complet, l'extension .gguf et le nom du fichier.
  • Manque de mémoire : ferme les applications inutiles et choisis un modèle ou une quantification plus légère.
  • Modèle en plusieurs parties : vérifie que tous les fragments sont présents et que le motif du Modelfile les correspond.
  • Mind-It ne détecte pas Ollama : vérifie qu'Ollama est démarré et que l'adresse locale est correcte.
